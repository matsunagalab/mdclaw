# MDPrepBench (moved)

MDPrepBench now lives in its own public repository:
<https://github.com/matsunagalab/MDPrepBench>. The dataset, harness package
(`mdprepbench`), operator tooling, tests, and operating documentation moved
with it.

What remains here is MDStudyBench — see `mdstudybench.md` — and the shared
runner script `benchmarks/tools/run_mdprepbench_all_agents.py`, whose canonical
copy is in the MDPrepBench repository and which stays only because the
MDStudyBench batch wrapper builds on it.
